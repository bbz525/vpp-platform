# T07 告警中心契约

## 产品闭环

值班运营员进入告警中心，先确认规则覆盖是否完整，再按严重度和状态查看活动异常；打开告警后核对对象、最近发生时间、次数及原始证据，随后确认或备注。条件消失时系统进入 `RECOVERED`，人员可确认或核对恢复事实后关闭，所有动作保留时间线与审计。

## 状态语义

| 状态 | 含义 | 可执行动作 |
| --- | --- | --- |
| `OPEN` | 条件成立，尚未确认 | 确认、备注 |
| `ACKNOWLEDGED` | 人员已知晓，但条件可能仍成立 | 备注、关闭 |
| `RECOVERED` | 条件已消失，不代表人员确认 | 确认、备注、关闭 |
| `CLOSED` | 生命周期已结束，只读 | 查看时间线 |

- 重复异常只增加同一活动实例的 `occurrence_count` 与 `last_occurred_at`。
- 恢复不是确认；`OPEN` 和 `ACKNOWLEDGED` 均可由系统转为 `RECOVERED`。
- 已恢复条件再次出现时回到 `OPEN` 并清除旧确认信息，必须重新确认。
- `CLOSED` 后条件仍成立或再次触发会创建新实例，因此关闭活动异常不会形成静默。
- 无证据、规则服务异常或规则尚未接入事实源时必须显示覆盖不足。
