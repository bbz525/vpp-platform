# T08 日前预测中心契约

预测面向站点或同一时区的资源组合，按目标本地日输出左闭右开的 15 分钟区间。普通日 96 点，夏令时切换日由 IANA 时区产生实际 92/100 点，统一以 UTC 时间戳存储。

## 真实性边界

- Platform API 冻结 `data_cutoff`；Forecast Service 只接受严格早于截止点的观测。
- 只使用 `VALID` 数据。至少 28 个达到 80% 日覆盖率的历史日，且截止日前近 7 天总体完整率至少 95%。
- 不满足门禁返回 `INSUFFICIENT_DATA` 与原因，不补零、不生成随机曲线。
- MVP 模型为 `similar-day-average-v1`：优先使用过去八个同星期日，缺失时回退最近七日同一时段均值；不声称未经真实数据验证的精度。
- 误差采用最近七日滚动起点验证，每个验证日只可见更早历史，报告 MAE、WAPE、nMAE 和实际评估点数。

## 版本与审计

成功运行记录模型、特征、天气来源、数据截止点、数据集报告和验证指标。预测版本/点位只追加；人工修正只能从最新版本生成子版本，保留原因、操作者与原值，并进入不可变审计日志。下游调度必须引用具体 `forecast_version_id`。

## UI 状态

控制台分别展示负荷与光伏的未生成、等待、运行、数据不足、失败、成功状态。成功显示真实点序列、模型版本、截止点、历史天数和滚动指标；不足或失败显示机器原因，不以演示数据代替结果。
